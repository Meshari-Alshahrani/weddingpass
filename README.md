# WeddingPass 💍

منصة حديثة ومتكاملة لإدارة دعوات الزواجات والمناسبات، تأكيد الحضور (RSVP)، وإصدار بطاقات الدخول الآمنة بالـ QR ومسحها عند البوابات.

---

## 🌟 المميزات الرئيسية

### 1. روابط المجموعات وقروبات الواتساب (Smart Group Links)
* إنشاء روابط مخصصة للقروبات والمجموعات (`/join/[slug]`) مثل قروب العائلة أو الزملاء.
* تسجيل ذاتي خاطف للضيف في أقل من 3 ثوانٍ مع دعم الملء التلقائي للاسم ورقم الجوال.
* خيارات مرنة للحد الأقصى (مفتوح بالكامل / تنبيه عند التجاوز / إغلاق صارم).
* استرجاع فوري لبطاقة الدخول برقم الجوال في حال فتح الرابط من متصفح مختلف.

### 2. الدعوات الخاصة الملكية وتأكيد الحضور (RSVP)
* تصميم فاخر مع عد تنازلي وتحديد الموقع على Google Maps وإضافة للتقويم.
* تحديد دقيق لعدد الحاضرين الفعليين من كل دعوة.
* توليد بطاقة دخول مستقلة (Digital Boarding Pass) مع إمكانية حفظها كصورة عالية الجودة في ألبوم الصور.

### 3. تطبيق ماسح البوابات (Gate Scanner PWA)
* يعمل مباشرة من كاميرا الجوال لموظفي الاستقبال عند بوابات القاعة (`/checkin`).
* **دعم العمل بدون إنترنت (Offline-First)**: التحقق المحلي في أقل من 50ms مع طابور مزامنة تلقائي فور عودة الاتصال.
* حماية مباشرة ضد تكرار مسح نفس البطاقة (Double Check-in Prevention).
* تنبيهات صوتية واهتزازات حسية مع خيار تعديل العدد الفعلي الواصل عند الباب فوراً.

### 4. لوحة تحكم المنظم وشاشة المراقبة المباشرة
* استيراد وتصدير قوائم الضيوف وتقارير الحضور بملفات Excel / CSV.
* إرسال سريع للرسائل الشخصية عبر WhatsApp بنقرة واحدة.
* شاشة عرض حية (`/admin/live`) مخصصة لشاشات القاعة لمتابعة تدفق الضيوف ونسبة الحضور لحظة بلحظة.

## 🛠️ البنية التقنية

* **الإطار البرمجي**: Next.js (App Router) + React 19 + TypeScript
* **التنسيق والتصميم**: Tailwind CSS + Framer Motion + Lucide Icons
* **قاعدة البيانات**: PostgreSQL / Supabase
* **التخزين والأمان**: SHA-256 Hashing + IndexedDB Local Cache
