## ⚡ التشغيل السريع للمشروع

```bash
# 1. تثبيت الحزم البرمجية
npm install

# 2. تشغيل حزمة اختبارات الأمان والجودة المؤتمتة
npm test

# 3. بناء نسخة الإنتاج للتحقق
npm run build

# 4. تشغيل السيرفر المحلي للتطوير
npm run dev
```
