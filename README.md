# WeddingPass 💍
### منصة إدارة بطاقات الدخول الملكية وضبط بوابات الأعراس (v5.9.4)

منصة حديثة ومتكاملة لإدارة دعوات الزواجات والمناسبات الفاخرة، تأكيد الحضور (RSVP)، إصدار بطاقات الدخول الآمنة المشفرة، ومسحها الذري عند البوابات بمعايير أمان OWASP وقواعد بيانات Supabase PostgreSQL 2026.

---

## 🌟 المميزات الرئيسية

### 1. روابط المجموعات وقروبات الواتساب (Smart Group Links)
* إنشاء روابط مخصصة للقروبات والمجموعات (`/join/[slug]`) مثل قروب العائلة أو الزملاء.
* تسجيل ذاتي خاطف للضيف في أقل من 3 ثوانٍ مع دعم الملء التلقائي للاسم ورقم الجوال.
* خيارات مرنة للحد الأقصى (مفتوح بالكامل / تنبيه عند التجاوز / إغلاق صارم للكوتا مع قفل ذري سحابي).
* استرجاع فوري لبطاقة الدخول برقم الجوال في حال فتح الرابط من متصفح مختلف.

### 2. الدعوات الخاصة الملكية وتأكيد الحضور (RSVP)
* تصميم فاخر مع عد تنازلي وتحديد الموقع على Google Maps وإضافة للتقويم (RFC 5545).
* تحديد دقيق لعدد الحاضرين الفعليين من كل دعوة وإمكانية طلب كرسي متحرك للمسنين.
* توليد بطاقة دخول ذكية ومستقلة (Digital Boarding Pass) مع إمكانية حفظها كصورة عالية الجودة في ألبوم الصور.

### 3. تطبيق ماسح البوابات الذكي (Gate Scanner PWA)
* يعمل مباشرة من كاميرا الجوال لموظفي الاستقبال عند بوابات القاعة (`/checkin`).
* **توثيق أمني بجلسات HMAC مشفرة** وكوكيز `__Host-gate_session` الآمنة.
* **دعم العمل بدون إنترنت (Offline-First)**: التحقق المحلي في أقل من 5ms مع طابور مزامنة تلقائي فور عودة الاتصال.
* حماية مباشرة ضد تكرار مسح نفس البطاقة (Anti-Replay Attack).
* توجيه الأقسام التبادلي وتنبيهات كبار الشخصيات (VIP) الملكية.

### 4. لوحة تحكم المنظم وشاشة المراقبة المباشرة
* استيراد وتصدير قوائم الضيوف وتقارير الحضور بملفات Excel / CSV محصنة ضد حقن المعادلات.
* إرسال سريع للرسائل الشخصية عبر WhatsApp بنقرة واحدة.
* شاشة عرض حية (`/admin/live`) مخصصة لشاشات القاعة لمتابعة تدفق الضيوف وتبريكات الحضور لحظة بلحظة.
* نقطة فحص البنية التحتية والفحص الإداري المسبق (`/api/health` و `/api/admin/system-health`).

## 🛠️ البنية التقنية (Enterprise Stack)

* **الإطار البرمجي**: Next.js 16 (App Router) + React 19 + TypeScript
* **المعمارية**: Repository Pattern Architecture مع تطبيق Fail-Closed الصارم بالإنتاج
* **التنسيق والتصميم**: Tailwind CSS + Lucide Icons + الخطوط الملكية
* **قاعدة البيانات والتخزين**: Supabase PostgreSQL مع Zero-Trust RLS ودوّال RPC الذرية بقفل `FOR UPDATE`
* **التشفير والأمان**: True HMAC-SHA256 Sessions + SHA-256 Hashes + OWASP Session Management
