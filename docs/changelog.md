## 🏷️ سجل الإصدارات التاريخي

### [v5.4] - 2026-08-22 18:45 (Infrastructure & Platform Hardening)
* **المعمارية والأمان السحابي:**
  - إضافة ترويسات الأمان الصارمة في `next.config.ts` (`X-Frame-Options: DENY`, `HSTS`, `nosniff`, `Permissions-Policy`).
  - تطبيق سياسة `force-dynamic` و `no-store` لمنع تسمم الكاش السحابي للبطاقات الفردية عبر Vercel Edge.
  - حصر نطاقات الصور المصرح بها `remotePatterns` على Supabase Storage لمنع استنزاف سيرفر التحسين.
  - تحصين دوال PostgreSQL في `schema.sql` عبر تثبيت `SET search_path = public, pg_temp;` (CVE-2018-1058).
  - حظر بث التغييرات الحساسة لجدولي `parties` و `entry_passes` عبر قنوات Supabase Realtime المفتوحة.

## 🏛️ سجل القرارات المعمارية (Architecture Decision Records - ADRs)

### ADR-001: فصل رموز الدعوة عن رموز بطاقات الدخول (Token Decoupling)
* **القرار:** استخدام رمز `wp_inv_...` لفتح الدعوة، وتوليد رمز منفصل `wp_pass_...` للباركود بعد تأكيد الحضور فقط.
* **السبب:** منع أي شخص يفتح رابط الدعوة من الدخول للقاعة دون تسجيل وتأكيد صريح لمقاعده، ولحماية قاعدة البيانات بتخزين الـ SHA-256 Hashes فقط.

### ADR-002: اعتماد النمط الهجين للاختبارات (Unified Runner + Domain Docs)
* **القرار:** تشغيل فحص شامل عبر مشغل موحد فائق السرعة `npm test`، مع توثيق الاختبارات مفصلة حسب القطاع الوظيفي.
* **السبب:** ضمان سرعة التنفيذ في بيئات الـ CI/CD ومنع نسيان أي فحص، مع منح المطورين وضوحاً كاملاً في التوثيق.
