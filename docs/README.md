## ⚡ التشغيل السريع للمشروع

```bash
# 1. تثبيت الحزم البرمجية
npm install

# 2. تشغيل حزمة اختبارات الأمان والجودة المؤتمتة (48/48 اختباراً)
npm test

# 3. بناء نسخة الإنتاج السحابية
npm run build

# 4. تشغيل السيرفر المحلي للتطوير
npm run dev
```

## 🗄️ قاعدة البيانات

ملفات [`supabase/migrations/`](../supabase/migrations/) هي المصدر الوحيد المعتمد لمخطط Supabase، وتُطبّق بالترتيب عبر Supabase CLI أو أداة الترحيل في بيئة النشر. ملف `supabase/FULL_SETUP.sql` متقاعد عمدًا ولا يجب تشغيله، لأنه كان نسخة مجمعة قديمة واختلف عن المخطط المعتمد.
